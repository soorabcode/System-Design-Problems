# System Design Problems

A collection of practical System Design interview problems, covering the design of scalable, reliable, and high-performance systems.

## Problems

Each problem is organized into its own directory with a write-up, a design diagram, and a working Python implementation.

| # | Problem | Description | Solution |
|---|---|---|---|
| 1 | **TinyURL — URL Shortener** | Design a service that converts long URLs into short links and redirects users to the original URLs. | [View Solution](./TinyURL/) |
| 2 | **Ticket Booking** | Design a ticket booking platform where users can browse events, select seats, and book tickets without double-booking. | [View Solution](./Ticket-Booking/) |
| 3 | **E-Commerce** | Design an e-commerce platform covering product search, cart, checkout, orders, and payments at scale. | [View Solution](./E-Commerce/) |
| 4 | **OTT Platform** | Design a video streaming platform with accounts, subscription plans, search, and video playback for millions of users. | [View Solution](./OTT-Platform/) |
| 5 | **Hotel Booking Platform** | Design a hotel booking system with search, hotel details, booking, and payment, ensuring consistent bookings under high load. | [View Solution](./Hotel-Booking/) |

More system design problems will be added as the collection grows.


## Goals

- Practice solving real-world system design problems.
- Understand the reasoning behind architectural decisions.
- Explore high-level and low-level design approaches.
- Build a useful reference for system design interviews.
- Improve understanding of scalability, performance, and reliability.
